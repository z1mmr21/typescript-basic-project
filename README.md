# TypeScript Базовий Проєкт

Цей репозиторій містить базову конфігурацію TypeScript проєкту з демонстрацією основних типів.

## Опис

Проєкт створено для демонстрації:
- Налаштування TypeScript з нуля
- Використання базових типів TypeScript
- Компіляції TypeScript коду в JavaScript

## Структура проєкту

- `src/` - вихідні TypeScript файли
- `dist/` - скомпільовані JavaScript файли
- `tsconfig.json` - конфігурація TypeScript

## Встановлення
```bash
npm install
```

## Компіляція
```bash
npm run build
```

## Запуск
```bash
node dist/index.js
```
